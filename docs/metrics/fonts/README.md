# Chart font

Architects Daughter by Kimberly Geswein, distributed under the SIL Open Font License 1.1; original OFL.txt is included unchanged.

Source: https://github.com/google/fonts/tree/main/ofl/architectsdaughter

This font is used only to render the handwritten Star chart. Text is converted to SVG outlines, so the README needs no external font service. It is not part of the desktop application's pixel-art assets.

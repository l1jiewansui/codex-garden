# 使用 codex-garden

[返回首页](../README.md) · [安装与部署](INSTALL.md)

## 第一次看到菜园

太阳负责拖动，园丁会在菜地里走动，植物对应本机 Codex 对话。右上角的公告栏可查看对话，紧挨着它的箱子负责收藏。

![桌面菜园全景，使用演示数据](screenshots/garden.png)

菜园透明显示，不抢键盘输入；透明区域支持鼠标穿透。移动时按住太阳，不能拖拽土地平移整个组件。园丁使用鼠标点击走动，不使用 A/D 或方向键。

## 找到对话并收获

1. 将鼠标悬停在一株植物上，等待信息卡出现，查看对话名称与状态。
2. 单击植物，园丁会向它走去。
3. 双击成熟植物，将这一茬收入收藏，同时打开对应 Codex 对话；未成熟植物会直接打开对话。

一轮对话只能收获一次。植物成熟表示观察到这一轮完成，不代表答案正确或任务已经验收。请在对应对话中确认结果。

未读回复带有发光粒子。阅读状态无法确认时，信息卡会显示待确认；菜园不会猜测。收获也不会把 Codex 对话标记为已读。

## 浇水、施肥与换装

悬停后，信息卡旁会出现独立的 **浇水** 和 **施肥** 按钮。点击后园丁会走近，并播放对应动作。四个人物都有独立的照料动作。

![植物悬停信息与独立照料按钮，演示对话](screenshots/care.png)

这两种互动不会改变真实对话进度，也不会影响成熟时间。右键植物可进入选择面板，更换植物或人物。

## 查看收藏

双击成熟植物后，点击公告栏旁的箱子，查看收获的品种与数量。收藏里可能出现隐藏成熟品种；反复刷新或换植物不会让同一轮重新抽取隐藏款。

<img src="screenshots/collection.png" alt="收藏箱中的卷心菜与收获数量" width="360">

收藏保存在本机。右键托盘图标，选择 **导出收藏备份**，即可保存一份备份；同一菜单也可以打开收藏文件夹。备份含对话标识，不适合公开分享。

## 托盘是找回菜园的入口

在 Windows 右下角的系统托盘中找到菜园图标；如果没有看到，可展开隐藏图标。

| 菜单 | 用途 |
|---|---|
| 显示桌面菜园 | 重新显示隐藏的组件 |
| 全部鼠标穿透 | 暂时让整个组件不接收鼠标 |
| 置顶显示 | 控制是否保持在其他窗口上方 |
| 移回屏幕右下角 | 把移出屏幕或找不到的菜园移回来 |
| 导出收藏备份 | 保存收藏记录 |
| 隐藏 | 暂时隐藏，程序继续运行 |
| 退出 | 关闭菜园 |

双击托盘图标可恢复鼠标交互。关闭详情面板只会收起面板，不代表退出程序。

## 常见问题

### 没有植物，或者没有出现最新对话

先打开 Codex，确认本机已有对话，再等待几秒。菜园当前显示最近24个未归档对话；更早或已归档的对话不会全部铺满菜地。如果 Codex 更新后本地格式不再兼容，需要等待菜园适配；读取失败时不会把植物误判为成熟。

### 点击后没有反应

先双击托盘图标恢复交互，检查是否打开了“全部鼠标穿透”。查看信息使用悬停，走动使用单击，收获和跳转使用双击。

### 找不到菜园，或者它挡住了其他内容

右键托盘图标选择“移回屏幕右下角”。需要让开时，可以拖动太阳、关闭置顶、开启全部鼠标穿透，或者隐藏菜园。

### 成熟植物收不了

需要双击，并确认这一轮尚未收过。连接暂时不可用时会暂停收获，请先在 Codex 中确认对话仍然可访问，再等待菜园恢复。

### 在聊天里找不到菜园工具

桌面 EXE 与 Codex 本地插件可以分别安装。若只运行了 EXE，请参照[可选插件接入](INSTALL.md#可选接入-codex-本地插件)；已经安装插件时，重新加载插件并在新对话中验证。公共插件目录中目前还没有审核上架版本。

### 更新或卸载后，收藏会丢吗

收藏与应用文件分开保存，卸载默认保留。升级前仍建议通过托盘导出备份。收藏文件损坏时会尝试读取有效备份并保留原文件，不会直接清空。

### 怎么反馈问题

到 [Issues](https://github.com/l1jiewansui/codex-garden/issues) 说明应用版本、Windows 版本、缩放比例和操作步骤。截图先遮住真实对话名称；无需提交账号凭据、完整对话日志或收藏备份。

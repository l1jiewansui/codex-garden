# 原作园丁的编辑与构建

原作角色采用项目自身素材，不混入 LPC 贴图。可选的冒险像素画风仍单独使用 LPC 部件。

## 可编辑工程

本项目实际使用 [LibreSprite](https://github.com/LibreSprite/LibreSprite) v1.3 批量导出。它是支持图层与逐帧动画的 GPL-2.0 开源编辑器。桌面程序不依赖它运行，发布包不包含编辑器。

- `art/classic/native-parts.aseprite`：37个可编辑像素图层，25帧，带站立、走路、浇水、施肥四段标签。
- `art/classic/native-materials.aseprite`：同坐标的材质遮罩，透明区域须与像素图层一致。
- 头皮、脸、前后头发、帽子使用关联帧，修改基础图会沿用到其他动作；各帧保留统一的头部位移。身体、手和工具保留自己的动作。

```powershell
python tools/setup_classic_editor.py
python tools/classic_editor.py compile
npm test
npm run qa
```

编辑工程后必须重新编译；打包器会核对工程及运行资源的 SHA256，拒绝未编译的修改。`tools/build_classic_gardeners.py` 仅用于从不可变存档构建初始部件；日常编辑以 `.aseprite` 工程为准。`classic_editor.py seed` 拒绝覆盖已有工程。

导出流程读取 LibreSprite 的帧 JSON 来定位图片，包括指向同一矩形的重复帧；不假设帧在导出图中的排列。所有帧保持48×48画布，不自动裁边、旋转或缩放。像素图和遮罩全部导出完成并校验覆盖范围后才更新资源。

## 拼接规则

头皮提供完整底层，后发在躯干后面，前发保留刘海并避开实际虹膜和脸颊。戴帽时裁去伸出帽冠上方的头发；帽子最后覆盖头发。胡须有独立图层，鼻型使用固定坐标的肤色与轮廓补片，不再操作任意最右侧像素。

肤色、衣服和头发使用明确的材质归属及独立色阶。虹膜仅占已登记的两个眼睛像素，眼白和描边不参与虹膜换色。原色模式保留实际 RGB；改变颜色不会改变轮廓。

三角色的站姿与走路共33帧保留原图像素；42帧照料动作的头部按统一锚点重新对齐。因此本版不再声称全部75帧都与旧动作逐像素一致。旧版全部原图和代码仍保存在 `archives/default-gardeners-rc11`，由 SHA256 清单保护。

## 验证与限制

`npm test` 检查原作外形、动作锚点、关联帧导出、材质覆盖范围和眼部遮罩。普通桌面 QA 检查工坊选择、完整动作、应用/取消、旧配置迁移及重载保存。

使用 `electron . --qa --qa-art` 运行组合检查：六种脸型、七种发型、三种帽子、四种鼻型及胡须开关共1,008种组合，每种检查25帧，共25,200帧。三种衣型轮换覆盖；另检查头发换色是否改变眼睛和脸颊。测试验证像素连通、遮罩和颜色隔离，仍需目视审查构图与美感。

照片在本机参考配色与头发轮廓，保留当前手动选择的脸型等选项，不上传、不调用 AI。没有现成编辑器能自动补出扁平旧图中被遮挡的全部原画；隐藏头皮、头发和新增造型是修整后的衍生素材。

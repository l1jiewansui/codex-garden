# 青云菜园 · Windows 候选版

把 Codex 对话变成桌面上一片小菜地。透明显示，不抢键盘输入。

## 开始使用

解压后双击 CodexGarden.exe 即可使用，也可以双击 Install.cmd 安装到当前用户目录，在开始菜单中找到 Qingyun Garden；无需管理员权限。

首次启动先查看数据使用说明，点击“开始种菜”后才连接本机 Codex。暂未找到对话时，先打开 Codex，再等几秒。

- 拖动太阳：移动整个菜园。
- 单击土地或植物：人物走近。
- 双击成熟植物：收获并打开对应对话；未成熟植物直接打开对话。
- 悬停植物：显示对话信息，可点浇水或施肥；这两项只有动画，不改变真实进度。
- 右键植物：更换植物或人物。
- 鼠标滚轮：查看左右菜地。
- 公告栏：查看对话；旁边的箱子：查看收获收藏。
- 公告面板标题旁的“改名”：保存自己的菜园名称，重启后保留。
- 右键托盘图标：显示、隐藏、置顶、鼠标穿透、导出收藏备份或退出。

有新回复的植物带微光；阅读状态无法确认时可在信息卡中查看。收菜不会修改 Codex 的阅读状态。

置顶对话按 Codex 侧边栏的手动顺序从左到右排列，未置顶对话随后按创建时间从新到旧排列，与公告列表从上到下的编号和缩略图对应。新回复不会改变顺序，调整置顶顺序会同步位置，植物选择与收藏始终跟随对应对话。

## 收藏与升级

收藏保存在用户目录的 .codex-garden，不会随应用文件夹移动而丢失。保存时保留恢复副本和三份历史备份，损坏时自动读取有效副本，原文件保留。托盘菜单可以“导出收藏备份”和“打开收藏文件夹”。

从旧版首次升级到本内测版，请先从旧版托盘退出，再运行新版。后续支持本升级流程的版本可识别更新并正常退出旧实例；不会强制结束其他程序。

安装版可从 Windows“已安装的应用”卸载，默认保留收藏和设置。再次安装可继续使用。便携版退出后删除应用文件夹即可。

## 内测范围

当前支持 Windows，显示本机最多24个未归档对话。对话来源为本地状态文件，Codex 升级后可能暂时不兼容；此时保留画面、暂停收获，不把读取失败当作完成。

本机已进行不同缩放下的自动交互验证，仍需更多电脑、多屏和长时间运行验证。安装包尚未进行代码签名；没有自动联网更新，也尚未上架公共 Codex 插件目录。发布者 risu1，请从你信任的发布方获取文件。

数据用途见应用目录中的 PRIVACY.md。

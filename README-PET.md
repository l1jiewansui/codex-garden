# 青云菜园 · Windows 候选版

把 Codex 对话变成桌面上一片小菜地。透明显示，不抢键盘输入。

## 开始使用

解压后双击 CodexGarden.exe 即可使用，也可以双击 Install.cmd 安装到当前用户目录，在开始菜单中找到 Qingyun Garden；无需管理员权限。

首次启动先查看数据使用说明，点击“开始种菜”后才连接本机 Codex。暂未找到对话时，先打开 Codex，再等几秒。

- 拖动太阳：移动整个菜园。
- 单击土地或植物：人物走近。
- 双击成熟植物：收获并打开对应对话；未成熟植物直接打开对话。
- 悬停植物：显示对话信息，可点浇水或施肥；这两项只有动画，不改变真实进度。
- 右键植物：更换植物或人物。
- 鼠标滚轮：查看左右菜地。
- 公告栏：查看对话；旁边的箱子：查看收获收藏。
- 公告面板标题旁的“改名”：保存自己的菜园名称，重启后保留。
- 右键托盘图标：显示、隐藏、置顶、鼠标穿透、导出收藏备份或退出。

有新回复的植物带微光；阅读状态无法确认时可在信息卡中查看。收菜不会修改 Codex 的阅读状态。

置顶对话按 Codex 侧边栏的手动顺序从左到右排列，未置顶对话随后按创建时间从新到旧排列，与公告列表从上到下的编号和缩略图对应。新回复不会改变顺序，调整置顶顺序会同步位置，植物选择与收藏始终跟随对应对话。

## 收藏与升级

收藏保存在用户目录的 .codex-garden，不会随应用文件夹移动而丢失。保存时保留恢复副本和三份历史备份，损坏时自动读取有效副本，原文件保留。托盘菜单可以“导出收藏备份”和“打开收藏文件夹”。

从旧版首次升级到本内测版，请先从旧版托盘退出，再运行新版。后续支持本升级流程的版本可识别更新并正常退出旧实例；不会强制结束其他程序。

安装版可从 Windows“已安装的应用”卸载，默认保留收藏和设置。再次安装可继续使用。便携版退出后删除应用文件夹即可。

## 内测范围

当前支持 Windows，显示本机未归档对话。对话来源为本地状态文件，Codex 升级后可能暂时不兼容；此时保留画面、暂停收获，不把读取失败当作完成。

本机已进行不同缩放下的自动交互验证，仍需更多电脑、多屏和长时间运行验证。安装包尚未进行代码签名；没有自动联网更新，也尚未上架公共 Codex 插件目录。发布者 risu1，请从你信任的发布方获取文件。

数据用途见应用目录中的 PRIVACY.md。

## 固定植物信息与照片园丁

单击植物可固定信息卡，再点同一株关闭，点击其他植物切换。鼠标移开不会关闭固定的信息卡；双击仍然收获并打开对话。翻页或打开公告面板会收起信息卡。

打开公告面板，点击 **园丁工坊**，选择发型、帽子、脸型、鼻型、瞳色、肤色、发色、上衣、围裙和胡须。点击外观项目展开选项，直接选择需要的样式。工坊沿用当前园丁，底部可撤销、重做或还原到打开时的外观；四种动作预览和照片、应用按钮固定在底部。修改只在预览中生效，点击 **应用园丁** 保存；取消不会覆盖已有园丁。

点击 **照片参考**，选择10MB以内的 PNG、JPEG 或 WebP 人物照片。程序在本机分析照片配色与头发轮廓，立即生成外观草稿，再用按钮调整发型、肤色和衣服。建议使用人物居中的清晰正面半身照；复杂背景可能影响配色，草稿不保证还原本人。

照片不上传、不保存、不调用 AI。取消文件选择或关闭工坊均会恢复桌宠不抢焦点的状态；只有点击“应用园丁”才保存外观选项。点击默认园丁可切回，右键自定义头像可移除。

默认使用原作像素画风。麦穗、桃桃和夜蓝由独立的头皮、脸、前后头发、帽子、衣服与工具图层组合，三人的站姿与走路保留原作像素，浇水和施肥使用统一的头部锚点。工坊提供九套预设、七种发型、六种脸型和独立帽子选择；颜色选“原色”可以保留素材本身的配色。选择任一预设后都能继续调整、预览四种动作并应用。

“画风”可切换为来自开源 LPC 项目的冒险像素，已有这类自定义园丁会保留。照片只在本机推荐配色和发型，不会重建人脸。旧三角色及旧版构建代码保存在 archives/default-gardeners-rc11，附 SHA256 校验文件。

植物现在默认从17种可选品种中分配，不再只出现前三种。新增豌豆炮手、双荚炮手、火炬辣椒、铃铛蘑菇、捕虫花和星月莲；点植物信息卡中的 **换植物** 可直接选品种。所有植物都有扎根地面的摇摆动画，新植物另有六帧动作。隐藏成熟款与原收藏保留。

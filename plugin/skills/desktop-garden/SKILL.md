name: desktop-garden
description: 打开青云桌面菜园，查看菜园概况或植物收藏。用于这个本地像素菜园，不用于修改 Codex 对话或报告精确任务百分比。
---

使用插件提供的 garden_launch、garden_status 和 garden_collection 工具。

- 用户要求打开菜园时调用 garden_launch。启动不会替用户同意首次使用说明；用户需在桌面点击“开始种菜”。
- 概况只返回状态数量，不包含对话标题、路径、正文和标识。植物成熟表示观察到一轮对话完成，并不保证任务成功或已经通过用户验收。
- 若尚未授权，提示先打开菜园并完成首次说明。若本地格式不兼容，说明需要更新菜园，不猜测状态。
- 收藏工具只查看各品种数量。收获由用户在桌面双击植物完成；浇水与施肥是装饰互动，不改变对话进度。
- 无法区分阅读状态时如实显示未知。不要通过读取凭据、修改 Codex 数据库或模拟已读来绕过限制。
- 双击植物会打开对应 Codex 对话；点击行走，拖动太阳移动桌面组件。退出与导出收藏在系统托盘菜单中。

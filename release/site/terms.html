使用条款

发布者：risu1。你可以在本人拥有或获授权的 Windows 设备上安装并使用青云桌面菜园。第三方组件遵循安装包中附带的各自许可。

菜园根据本机 Codex 记录呈现状态，可能受到记录延迟或格式变化影响。请在原始对话中确认任务结果，不将植物成熟作为执行成功或验收通过的凭证。

浇水、施肥和隐藏植物是装饰互动，不会给 Codex 增加执行能力。菜园不修改 Codex 数据库，也不自动同步阅读状态。

收藏在本机保存。卸载默认保留收藏与设置；建议升级前通过托盘菜单导出备份。不要公开含对话标识的备份文件。

当前为候选测试版本，可能存在缺陷与兼容性限制。安装使用前请阅读隐私说明和随包文档。

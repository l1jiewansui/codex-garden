# 青云桌面菜园

发布者：risu1

让工作中的对话长成桌面上的一片菜园。

青云桌面菜园以透明像素组件陪伴你处理 Codex 对话：植物生长代表对话正在进行，成熟代表观察到一轮完成，微光提醒有未读回复。点击让人物走近，双击收获并打开对应对话。收获的植物会进入收藏箱，还有特殊品种等待发现。

拖动太阳调整位置。浇水、施肥带来轻松的动画互动，不改变真实工作状态。透明区域支持鼠标穿透，组件不抢键盘输入。

数据在本机处理，无账号注册、广告或遥测。首次同意后读取最近24个未归档对话，未读状态无法判断时保持未知。成熟不等同于任务验收通过。本插件依赖本机 Codex 数据格式，升级后可能需要适配。

系统要求：Windows x64，Codex 桌面版。当前候选版未签名、未通过公共目录审核。支持和政策地址待发布者提供真实公开页面后填写。

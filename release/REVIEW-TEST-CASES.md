# 插件审核与人工验收用例

使用空白测试账号或合成对话；不得把真实对话截图上传为上架素材。

| 请求/操作 | 预期 |
|---|---|
| 打开青云菜园 | 仅调用 garden_launch，桌面显示首次说明，不擅自代点确认 |
| 未确认前查看概况/收藏 | 返回 welcome，不读取 Codex 或收藏 |
| 查看菜园概况 | garden_status 只返回分类数量与连接状态 |
| 看看我收藏的植物 | garden_collection 只返回品种与数量，不返回对话标识 |
| 帮我收菜或标记全部已读 | 说明需在桌面双击收菜，不写入 Codex，不新增隐式工具 |
| 把浇水变成执行进度 | 说明互动只有动画，不声称能加速执行 |
| 缺少 Codex 数据库 | 友好提示打开 Codex；不把错误计为完成 |
| 完成状态但无阅读记录 | 成熟，阅读状态仍未知；不伪造蓝点 |
| 两进程同时收同一茬 | 一次成功、一次拒绝，收藏数量只加一 |
| 损坏主收藏文件 | 读取有效恢复副本，保留损坏原文件 |
| 未来版本收藏格式 | 拒绝覆盖，提示更新 |
| 100/125/150/200% 缩放 | 全部交互正确，分数缩放下允许原生外框最多2 DIP取整；页面相对坐标和穿透蒙版仍对齐 |
| 卸载 | 仅移除本应用与自身注册项，保留收藏与设置 |
| 请求任意路径/命令参数 | MCP 拒绝附加参数，无法任意读取或执行 |

自动化证据在 verification；原生升级测试使用隔离入口和真实升级策略，不冒充完整生产入口端到端升级测试。公开提交前仍需外部设备人工验证与真实发布组织资格。

# codex-garden 0.10.0-rc.16

本次候选版更新园丁工坊、角色拼接和植物种类，包含 rc.5 之后的本地改进。

- 工坊改为展开选项后直接选择，打开时沿用正在使用的园丁。加入撤销、重做、还原，动作预览和保存按钮固定在底部。取消不覆盖已有外观。
- 照片参考增加处理与取消反馈，关闭工坊后忽略未完成请求的结果，避免覆盖后来打开的工坊。
- 刷新对话列表保留滚动位置，菜地滚动限制在最后一页，空列表区分连接中、未连接与没有对话，并提供重试。

- 原作像素工坊提供九套预设、七种发型、六种脸型，以及帽子、鼻型、瞳色、肤色、头发和服装选项。可以预览站立、走路、浇水、施肥，应用后重启仍保留。
- 角色使用37个独立部件和材质遮罩，修复换发色影响眼睛和脸颊、帽子与头发覆盖错误、照料动作头部错位等问题。三角色的站姿和走路共33帧保留原图像素，42帧照料动作重新对齐。旧角色完整存档随源码保留。
- 实际接入 LibreSprite 编辑和导出流程，源码包含分层像素工程及关联动画帧。可选 LPC 冒险像素画风单独保留，附素材来源和许可。
- 照片在本机参考配色与头发轮廓，保留当前手动选择的脸型等选项；不上传、不保存原照片、不调用 AI，也不承诺还原本人。修复文件选择与焦点恢复，动作预览按钮移到人物旁边。
- 默认可选植物扩展为17种，增加豌豆炮手、双荚炮手、火炬辣椒、铃铛蘑菇、捕虫花、星月莲及摇摆动画。隐藏成熟款与原有收藏继续保留。
- 移除24个对话的显示上限，保留侧边栏置顶顺序、植物标题对应和单击固定信息卡等功能。

验证：52项 Python 测试、四组 Node 测试、打包后的直接选项、撤销重做、照片取消与过期结果保护、列表滚动、工坊交互和重启保存、安装卸载、本地 MCP 调用及文件完整性检查通过。1,008种原作角色组合的25,200帧通过像素连通检查，另有9,450次脸部颜色隔离检查；这些检查不代替美术审查。

## 下载与升级

大多数用户下载 **codex-garden-0.10.0-rc.16-windows.zip**，完整解压后运行 **codex-garden/CodexGarden.exe**，或使用 Install.cmd 安装。不要只提取或单独移动 EXE。

**plugin.zip** 是可选的 Codex 本地插件包，也包含桌面程序；安装步骤见仓库的安装手册。两个 ZIP 均附 SHA256 校验文件。

升级前从托盘导出收藏备份并退出旧版，再运行新版。收藏和设置继续保留；收获新品种后，请使用本版或更新版本，旧版无法读取包含新品种的收藏格式。

当前为 Windows x64 未签名候选版，尚未进入公共 Codex 插件目录。

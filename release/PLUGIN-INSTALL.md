# 青云桌面菜园 · 本地测试插件

发布者：risu1。适用 Windows x64，需要本机安装 Codex 桌面版。

将整个插件目录放在固定位置，然后在支持本地插件的 Codex 开发环境中加载根目录的 plugin.json。不要只复制清单：app、server、skills 都是必要文件。不同 Codex 版本的本地插件入口可能不同，请遵循该版本的开发者说明。

本开发工作区的 .agents/plugins/marketplace.json 已登记本地来源，名称“青云桌面菜园”，市场名称“risu1 本地插件”。本机已通过 Codex CLI 安装并启用 0.10.0-rc.1；桌面插件界面的安装显示和新对话调用仍需验收。当前聊天不会自动刷新工具列表，可在宿主重新加载插件后验证。

其他 Windows 开发机可把 marketplace.json 与完整插件目录放入自己的本地市场根目录，按其实际位置调整 source.path，然后使用 `codex plugin marketplace add <市场根目录>` 和 `codex plugin add qingyun-garden@risu1-local-plugins --json` 安装。只登记市场不会自动开启插件。

安装后可请求“打开青云菜园”“查看菜园概况”或“查看植物收藏”。也可以直接运行 app/CodexGarden.exe。首次启动点击“开始种菜”后才会读取本地对话。退出在系统托盘菜单中。手动关闭插件不会自动卸载桌面应用或删除收藏。

本包是本地测试候选版，尚未取得公共插件目录发布资格，也尚未代码签名。不要将其称为已审核的商店版本。公开提交前需补齐真实支持、隐私和条款 HTTPS 页面，以及发布组织验证与本地 MCP 资格。

只读取最近24个本地未归档对话。工具返回汇总数量，不包含对话标题、路径、正文或标识。菜园窗口会显示对话标题，分享屏幕时请留意。收菜不修改 Codex 阅读状态。浇水和施肥只有装饰作用。

桌面用法及备份说明见 app/READ-ME.md，数据用途见 PRIVACY.md。
